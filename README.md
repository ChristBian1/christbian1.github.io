# chrisbianchet.github.io

Personal website for Chris Bianchet, built with Jekyll and hosted on GitHub Pages.

**Live site:** https://chrisbianchet.com

## About

This site serves as a personal portfolio and CV for Chris Bianchet — Senior Security Software Engineer at Microsoft.

## Pages

| Page | URL | Description |
|------|-----|-------------|
| Home | `/` | Bio, skills, and education |
| Experience | `/experience/` | Work history |
| Internships | `/internships/` | Internship history |
| Projects | `/projects/` | Personal and academic projects |
| Achievements & Activities | `/achievements/` | Awards, speaking, academic distinctions, and community involvement |

## Development

Built with [Jekyll](https://jekyllrb.com/) using a customized [Minima](https://github.com/jekyll/minima) theme.

To run locally:

```bash
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000`.

## Deployment

Automatically deployed via GitHub Pages on every push to `master`.
